# Synthetic populated-titleblock blank set

All job fields, sheet names, dates and revisions here are invented. There are no
customer names, addresses, logos, plans, models or private templates. The ordered
three-sheet list demonstrates shared fields, a per-sheet field override, a paper
size override and explicit revision/date overrides. The optional DXF output uses
the existing `cad` extra; select only `svg` when that dependency is unavailable.
