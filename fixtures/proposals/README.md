`oabm.proposals.symbols` implementation from merged baseline
`082a08a42f1e271d0690063a3a2195398cc57708`, using the existing independently
authored `tests/test_symbol_proposals.py::qualification` fake-transport calibration.
The baseline source was exported to an isolated temporary source tree; no current
serializer or binding repair was used to produce the artifact.

The synthetic clock was fixed to the value recorded in the fixture, and the
journal run UUID to `00000000-0000-4000-8000-000000000001`. The fixture contains source
manifests, synthetic adapter responses and paired finish receipts. All source
PDFs, identifiers and model labels come from public synthetic test helpers.
It does not contain private documents or live-provider qualification evidence.
