# PDF convergence fixtures

These fixtures are synthetic and public-safe. They contain no customer plan data.

`v1/simple-garage-convergence.json` intentionally reuses the existing synthetic
architectural garage fixture and the existing synthetic electrical recognition
fixture. It supplies only the registration needed to put the electrical PDF
observations into the architectural model frame plus the small set of expected
spatial-hosting facts owned by Gate D.

The convergence fixture does not redefine either lane's observations or create
a second semantic model.
