# Contracts

Canonical serialized contracts live here.

The model-contract issue owns the initial version. Do not create competing workstream-local schemas.

Contract v1 must cover:

- coordinate system and units
- stable object IDs
- levels / stories
- walls / slabs / ceilings / spaces
- doors / windows / openings
- electrical devices and equipment
- ports / connection points
- obstacles / route constraints
- 3D route centerlines and fitting decisions
- circuit / conductor metadata hooks
- provenance and confidence
- schema versioning and migrations
