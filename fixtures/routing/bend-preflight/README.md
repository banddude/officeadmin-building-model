# Synthetic conduit bend budgets

All geometry and IDs here were invented for regression testing. Radii are
arbitrary design inputs, not manufacturer specifications. `valid.json` has one
90 degree turn with adequate straight space. `short-offset.json` has two adjacent
90 degree turns separated by 0.5 m, insufficient for two 0.3 m tangent setbacks.
The expected JSON files pin the public API report and executable demonstration.
